## 数据流（一次会议的生命周期）

```
会议结束
  │
  ▼
① ASR转写 → transcript文本
  │
  ▼
② ExtractService → LLM抽取 → 结构化纪要JSON
  │   (决议/待办/责任人/风险 → 写入会议系统数据库)
  │
  ▼
③ IngestionService → 切分 → Embedding → PGVector入库
  │   (metadata: department, meeting_id, date)
  │
  ▼
④ 用户提问 "Q3定了什么？"
  │
  ▼
⑤ RagChatService:
  │   - 问题Embedding
  │   - PGVector Top5检索（按部门过滤）
  │   - 拼Prompt → DeepSeek生成
  │   - 返回答案 + 引用溯源
  │
  ▼
⑥ (Phase 3) Agent自动:
    - 提取待办 → 创建日历提醒
    - 发给责任人 → 企业微信/邮件
    - 跟进状态 → 下次会前提醒
```

## 技术选型决策表

| 组件 | 选型 | 理由 | 备选 |
|------|------|------|------|
| Java框架 | Spring Boot 3.3 | 你的主场，生态完整 | Quarkus |
| AI框架 | Spring AI 1.0 | 官方、和Spring无缝 | LangChain4j |
| Chat LLM | DeepSeek | 国内快、便宜、效果好 | 通义/GLM |
| Embedding | Ollama本地/nomic | 免费、离线可用 | 通义text-embedding-v3 |
| 向量数据库 | PGVector | 运维简单、权限灵活 | Milvus/Qdrant |
| 缓存 | Redis | 缓存回答+限流 | Caffeine本地 |
| 监控 | Micrometer + Prometheus | Spring生态原生 | SkyWalking |
| 部署 | Docker Compose | 一键起所有依赖 | K8s（进阶） |
